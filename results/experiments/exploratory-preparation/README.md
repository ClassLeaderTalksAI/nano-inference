# Exploratory run, excluded from final comparisons

This first batch exposed `prefix_preparation_full` (2–4 rejected arrivals in each
tenant trial). The preparation limit was 4, so this was not a clean scheduler
comparison. The original reports are preserved, including the early analyzer's
ungated assessments. Do not use those assessments as accepted performance claims.
The final harness flags unexpected rejections and sets the same bounded preparation
capacity (32) in both scheduling variants; production defaults remain unchanged.
See the subsequent `../control/` and `../metal/` runs.
